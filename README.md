# hermes-plugins

پلاگین‌های شخصیِ هرمس (Hermes Agent) — دسکتاپ و ایجنت. همه برای استفادهٔ خودم نوشته شده‌اند و
محل نصبشان دو پوشهٔ زیر است:

```
~/.hermes/desktop-plugins/<id>/plugin.js      ← پلاگین‌های رابط دسکتاپ
~/.hermes/plugins/<id>/                       ← پلاگین‌های سمت ایجنت (پایتون + منیفست)
```

## نصب

**پلاگین دسکتاپ** (فقط یک فایل، بدون بیلد):

```bash
cp -r desktop-plugins/<id> ~/.hermes/desktop-plugins/
# سپس در اپ: ⌘K → «Reload desktop plugins»  (یا برنامه را ببند و باز کن)
```

نام پوشه همان `id` پلاگین است و باید با آن یکی باشد. غیرفعال‌کردن هم از
Settings ▸ Plugins انجام می‌شود.

**پلاگین ایجنت**:

```bash
cp -r plugins/<id> ~/.hermes/plugins/
hermes config set plugins.enabled.<id> true   # یا از Settings ▸ Plugins فعال کن
# نیمهٔ پایتونی بعد از بستن و باز کردن اپ بالا می‌آید
```

> چند پلاگین دو نیمه دارند: `plugins/<id>/` (سمت ایجنت) + `desktop-plugins/<id>/plugin.js`
> (سمت رابط). برای نصب کامل، هر دو را کپی کن.
> در این مخزن فایل نشانگر `.hermes-package.json` نیامده تا کپیِ تازه *فعال* نصب شود.

## پلاگین‌ها

| پلاگین | سمت | کار |
|---|---|---|
| **sidebar-overlay** | دسکتاپ | سایدبار سشن‌ها را روی چت شناور می‌کند؛ روی پنجرهٔ بزرگ خودکار پین (ستون ثابت) و روی پنجرهٔ باریک شناور می‌شود. چیپ نوار وضعیت: خودکار / پین / شناور. کلیک روی چت پنل را می‌بندد. |
| **window-rim** | دسکتاپ | قاب رنگی دور لبهٔ پنجره تا بین پنجره‌های باز شناخته شود؛ رنگ/ضخامت/گردی گوشه از چیپ نوار وضعیت. |
| **pretty-sidebar** | دسکتاپ | سایدبار مرتب: نوار آیکونی بالای سایدبار، ردیف‌های سشن به‌شکل کارت، داک آیکونی بخش‌ها در پایین، و راست‌چین‌کردن عنوان‌های فارسی. |
| **vazirmatn-font** | دسکتاپ | فونت کل رابط روی Vazirmatn + راست‌چین‌کردن هر بلوکی که حرف فارسی دارد (سلول جدول، پاراگراف، فیلد فرم) و چپ‌چین‌ماندن کد. |
| **chat-wallpaper** | دسکتاپ | تصویر پس‌زمینه پشت چت‌ها با تنظیم شفافیت از نوار وضعیت. |
| **session-color-tint** | دسکتاپ | رنگ خودِ سشن را به دو جای دیگر همان چت هم می‌برد (نه فقط نقطهٔ سایدبار). |
| **session-changes** | دسکتاپ | «این سشن چه چیزی را عوض کرد؟» بدون git — فایل‌های تغییریافته/ساخته‌شده در طول سشن، حتی وقتی پوشه ریپو نیست. |
| **auto-topic** | دسکتاپ + ایجنت | عنوان‌گذاری خودکار سشن با ایموجی؛ دکمهٔ «✨ Auto-topic» در دیالوگ تغییر نام + بازنویسی مولد عنوان. |
| **opencode-launcher** | دسکتاپ + ایجنت | دکمهٔ «opencode»: سرویس OpenCode v2 را بالا می‌آورد و رابط وبش را در پنل پیش‌نمایش هرمس نشان می‌دهد (لینک جفت‌شدن یک‌بارمصرف). |
| **dsh-launcher** | دسکتاپ + ایجنت | همان الگو برای DeepSeek Harness (`dsh web`) روی پورت 3080، همراه RTL/فونت فارسی رابط dsh. |
| **file-opener** | ایجنت | مسیر بک‌اند برای «باز کردن فایل در ادیتور سیستم» (Kate، وگرنه پیش‌فرض OS) که پنل Changes صدا می‌زند — رندرر اجازهٔ اجرای پروسه ندارد. |

## نکته‌ها

- `hermes-memory-ui` اینجا نیست: پلاگین شخص ثالث از کاتالوگ است (مخزن خودش).
- لاگ‌ها و فایل‌های وضعیت (`serve.log`، `state.json`) و `__pycache__` آپلود نمی‌شوند.
- هر پلاگین یک فایل `plugin.js` مستقل است (ESM)؛ تنها importهای مجاز `@hermes/plugin-sdk` و `react` هستند.
- وابستگی بیرونی ندارد؛ همه با API خود اپ کار می‌کنند و با آپدیت‌های Hermes ممکن است سلکتورهای DOM جابه‌جا شوند (بدترین حالت: یک ویژگی بی‌صدا از کار می‌افتد و بقیه سالم می‌مانند).
